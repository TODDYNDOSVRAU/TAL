# T.A.L. — Totally Accurate Labs

Everything in `C:\dev` is a T.A.L. product. The full brand identity is in `C:\dev\TAL\identidade\Identidade_TAL_v1.2.pdf` (source: `Identidade_TAL.html`). Read it before any decision about visual identity, naming or copy that this file doesn't cover.

## Decision criterion

Before adding, removing, publishing or approving anything, answer three questions: what is the reason, what problem does it solve, and how do we know it was done correctly. If any answer is missing, don't do it yet.

## Principles (summary)

- **Precision:** behavior that is consistent, verifiable and predictable.
- **Completeness:** no half-built features; no options without a purpose.
- **Simplicity:** complexity stays inside; the experience is clear.
- **Integrity:** don't promise what isn't delivered, don't hide limitations, don't invent capabilities.
- **Evolution:** design for maintenance, compatibility and migration.

A feature is done only when it is tested, behaves predictably, handles failures and reports them. If something can't be verified, mark it as pending; never call it done.

## How to work (THINK LIKE T.A.L.)

Understand the real problem before executing. Justify every choice. Don't deliver halfway, and don't hide limitations. Pick the most correct solution, not the easiest. When something fails, record why and prevent the repeat. Never call a result "done" with "should work": say what was verified and how.

## Which skill for which task

One skill, `tal` (plugin `tal@tal`), covers everything below. It loads one reference per task, so unrelated references cost no tokens.

| Task | Skill / reference |
|---|---|
| Any decision, naming, "is it done?", checking work | `tal` (`review.md`) |
| Code, tests, security, performance, logs, metrics | `tal` (`code.md`) |
| Colour, font, logo, accent audit | `tal` (`brand.md`; script `brand-check.js`) |
| User-facing text, errors, signatures | `tal` (`voice.md`) |
| Video, motion graphics, reverse engineering, agents, tokens, memory, writing skills | `tal` (`video.md`, `motion.md`, `reverse.md`, `agents.md`, `tokens.md`, `memory.md`, `authoring.md`) |
| UI, motion, gesture, layout | `tal-apple-design` (with `tal` `ui.md`) |

The earlier skills `tal-core`, `tal-voice`, `tal-engineering` and `tal-brand-check` were merged into `tal` and moved to `~/.claude/skills-off/`. In a project without a T.A.L. block, `node <tal-skill>/scripts/init-claude-md.js` adds one; it skips folders that already inherit this file.

Priority on conflict: this file > T.A.L. skills > third-party skills. A third-party skill never introduces a colour, font, slogan or logo treatment outside the identity.

Pending, declared by the identity document itself: numeric targets for each product's measurements (T.A.R.K.A.S.: end-to-end latency, dropouts per hour, frequency-response deviation). Ask the owner; don't invent them.

1. **ESSENTIAL:** main actions, direct flow.
2. **ADVANCED:** detailed settings and parameters.
3. **ENGINEERING:** diagnostics, logs, metrics.

No "lite" or "pro" versions that are artificially limited.

## Visual identity

| Token | Hex | Use |
|---|---|---|
| Absolute Black | `#080808` | Backgrounds; main text on light |
| Precision White | `#F2F2F0` | Light surfaces; main text on dark |
| Technical Gray | `#6B6B6B` on light / `#8C8C8C` on dark | Secondary text (WCAG AA) |
| Ice / Deep Teal | `#7EE3EA` on dark / `#0D6C74` on light | Accent: what is active or ready, and points of attention, at most ~5% of a composition |

- **The accent is the T.A.R.K.A.S. blue, shared by the T.A.L. brand** (since 2026-10-30; it replaced Signal Lime `#C7FF32`, which is no longer used).
- **Ice never goes on a light background** (contrast 1.3:1); on light the accent is always Deep Teal (5.5:1).
- No colors outside the palette. Intermediate tones come from opacity on the base colors.
- **The logo never takes the accent:** it is always a single color.
- **Each product keeps its own accent color.** Don't replace a product's accent without asking. T.A.R.K.A.S. uses the same Ice / Deep Teal.
- **Fonts:** Space Grotesk for titles and identity, Inter for interface and body text, JetBrains Mono for code, metrics and technical data.
- **Logo (official, 2026-10-30):** three isometric line blocks (heights 3, 2, 1) with T, A and L in line strokes lying on top of each block, rounded joins, no color: white on black or black on white, with no lime and no blue.
  - **Files:** `AB-topo-negativo.svg` and `AB-topo-positivo.svg` in `C:\dev\TAL\logo\`, generated by `gerar.js`. Don't redraw them by hand. The other SVGs in the folder are earlier concepts, not the logo.
  - **Minimum size:** below 48 px use the blocks-only version (`B-camadas-*.svg`).
- **Minimum accessibility:** WCAG AA.
- **Motion:** 150–300 ms, with deceleration; respect reduced motion.

## Naming and signatures

- **Products:** the full name starts with "Totally Accurate…". The acronym forms a real word, with no invented spellings.
  - T.A.R.K.A.S.: Totally Accurate Real-Time Kind of Audio System
  - T.A.P.E.S.: Totally Accurate Picture Engine Studio
- **Fixed phrases:** signature `THINK LIKE T.A.L.`, seal `MADE BY T.A.L.`, support line `EVERYTHING HAS A REASON.` Don't create new slogans.
- **Where each one goes:**
  - Splash screen: `MADE BY T.A.L.`
  - About the app: "Developed by Totally Accurate Labs."
  - Footer: "© 2026 Totally Accurate Labs · MADE BY T.A.L."
- **Writing the acronym:** with periods in text (T.A.L.); lowercase without periods in domains, packages and file names (`tal`, `tarkas`, `tapes`).

## Voice

- **Precise, direct, honest and calm:** numbers and facts instead of adjectives; no exclamation marks, no emojis in system messages, no hype.
- **Errors:** say what happened and what to do. Example: "Não foi possível salvar: o disco está cheio. Libere espaço e tente de novo."
- **Language:** signature, seal and product names always stay in English. Interfaces follow the system language (at least PT and EN).

## Motion and interaction

For any UI, motion, gesture or feedback work, use the `tal-apple-design` skill: Apple-style fluid motion (springs, momentum, interruptible gestures), applied inside this identity. Where it conflicts with this file, this file wins.

## Existing projects

This file sets the standard for new work. When a project's own `CLAUDE.md` contradicts this file, follow the project's file and point out the conflict.
